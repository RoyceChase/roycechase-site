## Context

参考 docs/homelab-display-design.md；三个模型使用独立 HTML/CSS/JS，存在重名选择器和不同模型单位。

## Goals / Non-Goals

目标为在一个共同三维坐标中陈列设备，并验证从实物到逻辑结构的阅读路径。架子为展示假设，尺寸为视觉估算。实际服务名称与路由配置未确认，使用明确示意标签。

不修改已认可模型，不连接实际管理接口，不宣称服务实时状态，不完成正式网站接入。

## Decisions

- 用可重复生成的模块提取原模型几何初始化，Shadow DOM 隔离样式；共同父场景负责旋转，避免 iframe 独立视角。
- 页面内完整宽度 SVG 工作区使用紧凑节点与带方向的流动连线，SVG 节点支持按钮角色、焦点与 Enter/空格；手机保留拓扑，通过局部横向滑动保证文字可读。动画为路径示意，遵循减少动态效果偏好。
- 设备场景使用指针捕获与窗口级移动/释放处理，禁止选中文字和原生拖放；场景内 touch-action 为 none，场景外保留页面滚动，取消和失焦均清理拖动状态。
- hash 表达章节；节点选择不写入历史。详情常驻，避免弹窗承载长文。
- 按用户参考限制俯仰至 -28° / -2°，初始 -13°；拖动和键盘共用边界，水平旋转不限制，避免架子底部和完全俯视角度。
- 根据最新外观反馈，支架改为暖石墨色四格开放柜：顶板、侧板、错位隔板、内退背板与底座。上层两格分别放主机和路由器，下层宽格放 UPS，窄格留白。设备摘要仍位于模型上方；场景背景使用低饱和暖灰与暗橄榄灰过渡，设备原始材质保持不变。
- 模型使用 scale3d 的三个相同因子保持三轴比例；路由器按机身占地面积为迷你主机的 1/3 计算线性缩放，UPS 宽度为迷你主机的 1.5 倍。按缩放后的高度贴合层板，不单独拉伸模型宽度。

## Risks / Trade-offs

最新配色决策：汇总场景路由器使用黑色材质覆盖（不修改独立原型），柜体为偏黑石墨色，背景使用中性黑灰；保留主机银色与 UPS 黑色，设备几何、比例不变。

- 模型提取依赖原型结构 → 生成器断言初始化边界和节点存在，修改原型后显式重建。
- 3D 跨组件渲染 → 不对 Shadow host 设置会扁平化的 opacity/filter；浏览器验证实际场景。
- 架构未完全核实 → 服务仅用职责分组，网络路径标为示意，UPS 只标注已确认实测。
