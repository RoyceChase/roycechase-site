# Spec Delta

## Purpose

为个人工程师门户提供统一的配色、排版与响应式视觉行为，让访问者能够清晰识别个人身份、浏览文章和导航，同时在桌面、移动端以及不同外观模式下保持可读性与可操作性。

## ADDED Requirements

### Requirement: 统一配色与外观切换

网站 SHALL 在没有已保存外观偏好的首次访问中默认显示深灰背景、白色主标题、灰色正文和蓝色强调，并保留可读的浅色模式及手动切换入口。

#### Scenario: 首次访问
- **WHEN** 访客没有已保存的外观偏好并打开首页
- **THEN** 页面显示深色风格，正文、链接与导航清晰可读

#### Scenario: 手动切换
- **WHEN** 访客切换到浅色模式并刷新页面
- **THEN** 浅色偏好得到保留，文章、代码块和导航仍清晰可读

### Requirement: 门户首页视觉层次

首页 SHALL 以左对齐大标题展示 Royce Chase，显示 Backend Engineer 与现有简介，提供文章和 GitHub 入口，并保留最新文章列表。

#### Scenario: 桌面首页
- **WHEN** 访客在桌面打开首页
- **THEN** 姓名、职业、简介和主要入口具有明确层次，最新文章可以访问

### Requirement: 响应式导航与内容

网站 SHALL 使用圆角、细边框导航及一致的内容留白，在首页、文章和列表页保持统一风格；移动端不得出现由通用布局造成的横向溢出。

#### Scenario: 手机浏览
- **WHEN** 访客在 375px 宽度浏览首页、列表与文章
- **THEN** 标题自然换行、导航可操作，代码块在自身容器内滚动

### Requirement: 保留现有操作能力

样式调整 SHALL 保留搜索、文章链接、代码复制、移动菜单和键盘操作能力，并为交互元素提供可见焦点。

#### Scenario: 键盘访问
- **WHEN** 访客使用 Tab 移动到导航、搜索或主要入口
- **THEN** 当前焦点可见，入口可通过键盘激活
