# GL.iNet GL-MT3600BE 外形原型

依据用户提供的薄荷绿路由器产品图制作。独立 HTML + CSS 3D + JavaScript，无外部依赖；机身与天线比例为照片估算，不代表实测尺寸。

```bash
python -m http.server 1423 --bind 127.0.0.1 --directory docs/prototypes/glinet
```

打开 http://localhost:1423/ 。支持拖动、方向键旋转、缩放、自动旋转、各面切换及天线展开 / 收起。

主要细节：薄荷绿圆角外壳、壳体分界线、双扁平天线与铰链、侧面两排散热槽及按键示意、USB-C 电源口、WAN / LAN 双网口、蓝色 USB-A、顶部 GL.iNet 文字和另一面的指示灯。天线折叠和底部结构为外观示意，未复刻实际机构；指示灯不是实时状态。

天线朝向：两根天线绕竖轴分别旋转 ±90°，宽面与机身侧面平行，内侧贴近外壳；收起时沿机身纵深方向折叠。

收起对齐：天线调整为 54 × 226 个模型单位，绕转轴折叠至 90°，收起后与机身水平对齐，覆盖侧面风栅。折叠轮廓纵向约为 -114 到 112、竖向为 ±27，均在机身纵向 ±130 和厚度 ±33 的范围内；已检查侧视截图及手机布局。

验证：桌面立体与接口截图、折叠切换、375px 无页面横向溢出、方向键与自动旋转开关。iMini 和 UPS 模型未修改；本模型未接入 Hugo 或线上部署。后续正式集成时再用 OpenSpec 定义组件和位置配置。
