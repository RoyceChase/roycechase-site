# HomeLab 交互 MVP

发布状态：草稿。Hugo 入口为 `content/homelab/index.md`（`draft: true`），交互原型仍保存在本目录；默认 Hugo 构建不发布此入口，也不复制本目录。原型设置 noindex 和草稿元信息。后续正式接入页面并评审后再发布。

路由器朝向：水平旋转 180°，指示灯正面朝柜外，接口朝柜内；尺寸、位置及等比缩放不变。

最新配色：汇总场景路由器和四格柜均为黑色/石墨黑，场景背景中性黑灰。路由器通过 Shadow DOM 材质样式覆盖，未修改独立薄荷绿原型或模型尺寸；浏览器截图及计算样式已检查。

当前陈列：暖石墨色四格开放柜替代原双层支架，包含完整侧板、顶板、内退背板和错位隔板；上层分别陈列主机/路由器，下层 UPS 使用宽格，窄格保留留白。场景使用柔和暖灰色调，设备本身比例和材质不变。已检查桌面截图、390px 无横向页面溢出及 UPS 入口。

预览：在仓库根运行 `python -m http.server 1424 --bind 127.0.0.1 --directory docs/prototypes`，访问 <http://localhost:1424/homelab/>。

统一双层深灰架子场景中包含三个已认可设备模型；支持拖动/方向键旋转、设备摘要、四种架构视图、节点说明、其他虚拟机折叠说明、章节直达和返回。模型点击与名称按钮均可使用。设备说明位于场景上方，整体采用中性深灰背景和蓝色链接。

`build-models.py` 从相邻三个原型提取几何和样式，生成 imini.js / ups.js / glinet.js；原模型无修改。更新原型后运行 `python docs/prototypes/homelab/build-models.py`。组件用 Shadow DOM 隔离，共享父场景旋转，不使用 iframe 或动态脚本求值。

## 内容边界

- 架子、摆放为展示估算。按最新反馈，路由器机身占地面积为迷你主机的 1/3，UPS 宽度为迷你主机的 1.5 倍；使用 scale3d 同时缩放 X/Y/Z，原始几何比例不变；尚无完整实测尺寸。
- 服务使用分组占位，其他虚拟机未虚构名称；网络链路为概念路径，实际网关、代理方式和鉴权规则待补充。
- 用户确认 NUT 正常读取 UPS、断电自动关机已实测；不代表网页实时监控，不扩展宣称逐机退出或数据完整性已验证。
- 原型尚未接入 Hugo 导航，UPS 文章和正式发布另行实施。

## 验证

2026-10-15：浏览器检查三个设备几何加载（202 / 266 / 142 个 face）、共同旋转、直接选择 UPS、摘要入口、#power 直达、NUT 节点说明、其他虚拟机展开、视图切换和历史返回；390px 手机宽度无页面横向溢出，名称按钮支持键盘 Enter，加载无 pageerror。桌面人工截图检查架子与部署图。

`hugo --minify` 通过（主题最高支持版本提示仍存在）；`openspec validate homelab-interactive-mvp --strict` 通过。构建产生的已跟踪 public 输出已恢复，不纳入本变更。

同日评审调整：取消木纹和悬浮标签，改深灰架子、摘要上置；浏览器验证宽度比例约 0.333333 / 1 / 1.5，390px 布局无横向溢出，UPS → 停机保障 → NUT 说明链路正常。

后续纠正：前述宽度 1/3 被用户明确为机身占地面积 1/3；二维 scale 保持 Z 不变造成俯视拉长，现已统一使用 scale3d。浏览器验证各设备 X/Y/Z 缩放因子相同，路由器机身面积比约 0.333333，UPS 宽度比约 1.5。

俯仰限制为 -28° 至 -2°，默认 -13°：向俯视侧最多调整 15°，向平视侧保留 2° 俯角，避免仰视底部或完全俯视。拖动与方向键共用限制，水平旋转保持自由；已验证键盘和大幅拖动到达边界后不继续越界，复位恢复默认角度。

交互评审：阻止场景内文字选择、原生拖放与浏览器触屏滚动争用指针，窗口级处理拖动并在取消/失焦时清理。移除概览实测徽标，实测事实保留在正文。架构图改为紧凑 SVG 节点、直角链路和流动虚线，表示概念流向而非实时监控。小屏使用局部横向滑动保留拓扑；节点支持键盘，减少动态效果时禁用动画。浏览器验证四次连续鼠标拖动、CDP 触屏拖动、390px 无页面横向溢出及 reduce 下 animation-name 为 none。
