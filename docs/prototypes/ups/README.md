# APC Back-UPS 650 外形原型

依据用户提供的 BK650M2-CH 产品图片制作，独立 HTML + CSS 3D + JavaScript，无外部依赖。参考长 × 宽 × 厚为 286 × 171 × 105 mm，默认插座朝上平放；显示模型约按 1.25 倍换算为 CSS 单位。

```bash
python -m http.server 1422 --bind 127.0.0.1 --directory docs/prototypes/ups
```

打开 http://localhost:1422/ 。支持拖动、方向键旋转、缩放、自动旋转，以及插座面板、通讯侧、电源侧、底部视角切换。

已还原四位国标三孔插座、高低台阶与斜面、黑色控制区、绿色电源键、双充电 USB、APC 品牌文字示意、侧面散热槽及通讯 / 电源接口。底部电池仓及脚垫因参考不完整作简化，不代表精确结构或拆装方法。未使用商品图片、水印或实际序列号作为贴图。

验证：桌面立体 / 两侧 / 底部截图、四个插座、375px 无横向溢出、方向键及自动旋转开关。未修改 iMini 源码；未接入 Hugo 或发布到线上。后续正式集成使用 OpenSpec 记录需求及设备位置配置。
