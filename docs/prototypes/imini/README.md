# iMini 外形原型

基于用户提供的四张参考照片制作。独立 HTML + CSS 3D + JavaScript，无外部依赖；用于外形评审，尚未接入 Hugo 页面。

```bash
python -m http.server 1421 --bind 127.0.0.1 --directory docs/prototypes/imini
```

打开 http://localhost:1421/ 。拖动或方向键旋转，使用按钮查看正面、背面、顶部和底部，支持缩放与手动开启自动旋转。

外壳比例为 320 × 300 × 80 个模型单位，不代表实测毫米。顶部标志、散热孔、背部接口和底部脚垫为简化几何；未包含设备序列号或第三方照片。后续以实际尺寸校准，再拆分为正式设备组件并配置摆放位置。

验证：桌面多视角截图、375px 无横向溢出、方向键旋转、自动旋转开关。正式接入网站时建立 OpenSpec 变更并补充集成验证。

外形细化：圆角每象限细分为 48 段，移除分片边框并调整重叠，减轻黑色接缝；底部边框、格栅分区与筋条使用同一组正六边形坐标，加入黑色哑光喷漆纹理；侧面保持网孔宽度，高度从 24 降为 18，改用细密反光网格；背部接口缩为原来的 78%，增加银色顶部包边。已检查正面、背面、底部截图及手机布局。

第二轮细化：电源键白点使用双轴居中，增强按钮内外缘阴影，移除正面左下白线；顶部标志由同一半形旋转 180° 构成，对称居中。根据最新近照重新描绘斜向阶梯留白，两端窄缝、中间错位缺口露出机身底色；移除彩虹渐变，使用纯灰阶亮银高光，并随模型角度调整渐变方向。这是浏览器渐变模拟反射，不包含真实环境贴图或光线追踪。已检查放大标志、顶部 / 默认角度及手机无横向溢出。

反光修正：上下半形显式使用对称坐标，共享同一全局反射渐变，避免旋转半形连带反转材质。移除尖锐白色亮带，改用宽幅柔和明暗及微弱边缘；反射只随视角轻微偏移，避免转动时像扫光动画。几何轮廓和阶梯间隙保持不变。

最终外观：按用户最新选择，顶部标志使用纯深灰色 `#454545`，移除镜面渐变、描边和视角反射逻辑；保留已确认的对称轮廓与阶梯间隙。上方反光记录仅为设计迭代历史。
